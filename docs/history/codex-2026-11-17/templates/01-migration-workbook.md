# 서비스 전환 표준 작업서

기존 `docs_code/templates/T01`~`T10`은 상세 양식의 기준선이다. 아래 워크북은 문서별 입력과 승인하기 전에 남겨야 할 증거를 연결한다. 서비스가 하나여도 구현과 인터페이스, 시험, 운영 기록은 같은 요구사항 ID를 공유한다. 이후 Java 전환에서도 아래 계약과 fixture 집합을 재사용한다.

| 단계 | 입력 | 산출물 | 종료 기준 |

| G0 착수 | 업무 담당자, 원본 소스·설정·실행환경, 표본 | 범위·환경표, 의존성 목록, 변경 제한, 일정 | 작업 경계와 읽기/쓰기 대상 확정 |
| G1 요건·현행 | 외부 호출자, 스케줄러, 파일·TCP·DB 표본 | T01 요건·예외, T02 현행 호출 그래프, T05 인터페이스, T08 위험대장 | 정상·오류·중단·재실행 경로별 근거 첨부 |
