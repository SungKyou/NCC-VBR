# Agent 수신 자료 목록

2026-11-17. Agent의 이번 전환은 취소했다. 아래 자료는 CIFS와 Remove 전환 이후 Agent 전환 여부를 검토할 때 사용한다.

| 자료 | 확인 내용 | 남은 검증 |
|---|---|---|
| XenServer 9 콘솔 출력 `붙여넣은 텍스트.txt` | 조회 명령문 12개와 이어지는 출력이 있다. 대상 host UUID는 `0b1e66cd-f30a-4d12-9b17-f128048c8a59`, VM UUID는 `7bcbec74-924a-8c3c-bd43-a42fd5e98eaf`다. 호스트 상세에서 XenServer 9.0.0, VM 상세에서 `halted`, VBD/VDI와 `pending` Task 필드를 확인했다. | 명령별 종료 코드와 stdout/stderr 경계가 제공되지 않았다. 스냅샷 행은 확인되지 않았으므로 빈 결과와 명령 성공을 동일하게 판정할 수 없다. 실제 백업·복구 결과는 별도 검증이다. |
| `VBR 전문 예시.xls` | 사용자 제공 경로에서 파일이 읽히는 것을 확인했다. 크기 60,416 bytes. | 셀과 전문 내용을 이번 범위에서 판독·검증하지 않았다. 이후 검토 시 운영 로그와 대조한다. |
| 앞서 제공된 BACKUP 운영 로그 | 백업 결과 생성 성공과 TCP 결과 전송 실패 기록이 모두 있다. | 원인은 이 로그만으로 특정되지 않는다. |

원본 첨부 자료는 사용자 제공 위치에 보관한다. 이 목록은 수신과 확인 범위를 기록한다.
