# vbr_vm 착수서 (2단계)

기준일: 2026-11-19 / 유형: **B 재설계** ([절차 0장](../00-process/01-migration-process.md)) / 기준: 1단계 `vbr_agent` 3.000의 기능과 실기 결과(2026-11-18~19), 참조 규약 ncc-xen backend(`c:\dev\ncc-xen`, JobType 표준명세서 v3.36) / 작성: Claude Code

## 1. 목적

1단계 `vbr_agent`는 10년 전 설계의 고정 길이 문자열 전문(`B`+번호+종류+…)을 그대로 유지했다. 2단계는 같은 백업·복구 기능을 ncc-xen과 같은 JSON API 서비스로 새로 만든다. 이름은 `vbr_vm`이다. dom0에서 돌던 agent가 아니라 별도 서버에서 XAPI로 원격 실행하는 서비스라서 "agent"를 쓰지 않는다.

이 작업은 재설계 유형(B)에 표준 문서를 처음 적용하는 사례이기도 하다. 양식에서 부족했던 점은 바로 고치고 [절차 8장](../00-process/01-migration-process.md)에 남긴다.
