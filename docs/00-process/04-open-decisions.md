# 결정 대기 목록

사용자가 정해야 하는 항목이다. 정해지기 전까지 전환본은 "현재 구현" 열대로 동작한다.
결정하면 "결정" 열에 내용과 날짜를 적고, 관련 변경 대장 항목을 고친다.

기준일: 2026-11-19
